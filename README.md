# After the Hype — Brand Kit

Brand Kit de la identidad **Lima y Azul** de After the Hype: logos en todos sus formatos, color, tipografía, espaciado, radios, uso correcto y tokens para IA.

- `index.html` — la página del Brand Kit (estática, sin build).
- `assets/` — logos (SVG, PDF, PNG, JPG), favicon y app icons, `AfterTheHype_tokens.json` y `LEEME.txt`.
- `zips/` — paquetes descargables.
- `vercel.json` — cabeceras (noindex, caché).

Para enlazar una descarga directa del archivo .fig, completa `FIG_URL` en `index.html`.
